# DocuAsk — AI Document Intelligence

Source-controlled document Q&A: upload trusted files, ask in plain language, verify every answer with page citations.

## Stack

Angular · TypeScript · Python · FastAPI · SQLite / PostgreSQL · pgvector · Local or OpenAI embeddings · PDF.js

## Highlights

- Full-stack RAG workspace with Ask, Research, Compare, and Extract modes
- Hybrid retrieval, reranking, citation verification, and honest abstention
- Three-panel Ask UI with evidence panel and PDF page open-at-source
- User-level document isolation, JWT auth, Argon2 passwords
- Editorial portfolio UI with live document-knowledge network background
- Higher-education demo data for realistic portfolio scenarios
