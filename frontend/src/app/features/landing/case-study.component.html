Case study

Building a trustworthy document Q&A workspace

DocuAsk is a full-stack RAG product: upload files, ask questions, and verify answers against page-level citations. This write-up covers the problem, design choices, architecture, and hard parts — without invented metrics.

Problem

Handbooks, resumes, SOPs, and contracts already contain the answers people need — but searching a PDF is slow, and chatbots invent details when the file is silent. Recruiters and operators need a workspace that grounds every claim in a source page, not a generic assistant.

Design decisions

  • Citations first. Answers show document, page, and excerpt; the viewer jumps to the passage.
  • Insufficient is honest. If retrieval cannot support a claim, DocuAsk says it could not find enough information.
  • Editorial UI. Warm paper, charcoal type, and a quiet knowledge-network background — trust over spectacle.
  • Modes with one job. Ask, Research, Compare, and Extract share retrieval but differ in how evidence is presented.

Architecture

Angular talks to FastAPI with JWT auth. Uploads are processed into page-aware chunks, embedded, and stored with user and document ownership. Questions are rewritten and retrieved hybrid-style; answers are verified against retrieved text before citations are attached.

Angular → FastAPI → embeddings / vector search → document processing → auth → storage

Challenges

  • Two-column PDF layouts scramble title vs. body order — list answers needed structure-aware formatting.
  • Citations must match answer content, not the first chunk on a page (headers and cover letters look like “sources”).
  • Fallback when cloud LLM billing fails: extractive answers from retrieved passages still need readable structure.
  • PDF.js viewer compatibility across browsers required legacy workers and polyfills.

Results

The live product supports upload of PDF/Word/text, scoped Ask across one file or a library, page citations with viewer highlight, and a seeded demo handbook. The marketing surface explains the pipeline and security model without fake scale claims — so recruiters can evaluate the system by trying it.
